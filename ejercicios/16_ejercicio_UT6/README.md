# 16_ejercicio_UT6 · Elegir dónde y cómo guardar la información

**UT6 · RA6 · Nivel 1** — Almacenamiento y consulta: XML, JSON, SQL y bases de datos nativas

**RA6:** Gestiona la información en formatos de intercambio de datos analizando y utilizando tecnologías de almacenamiento y lenguajes de consulta.

**Criterios trabajados:** RA6 a), RA6 b), RA6 c), RA6 d), RA6 h)

## Situación

La almazara debe decidir cómo almacenar catálogo, pedidos y mediciones de los depósitos.

## Enunciado

1. Compara ficheros XML/JSON, base de datos relacional y base de datos nativa (XML o documental): estructura, consulta, concurrencia y tamaño recomendado.
2. Evalúa ventajas e inconvenientes de guardar documentos JSON/XML dentro de una base de datos frente a normalizar en tablas.
3. Elige la tecnología más eficiente para: facturas, fichas de producto con atributos variables, catálogo con transformaciones XSLT y lecturas de sensores de temperatura.
4. Relaciona XPath, XQuery, XSLT, JSONPath, `jq`, MongoDB Shell, BaseX y DataGrip con su función.

## Entrega

Una tabla comparativa y las elecciones justificadas.

## Criterios de aceptación (compruébalos tú)

- La tabla distingue estructura y consulta de cada opción.
- Cada elección se justifica con una característica de los datos.

## Pista

No hay una tecnología mejor en general: depende de la forma de los datos y de cómo se consultan.
