# 08_ejercicio_UT3 · Primeros pasos con JavaScript y el DOM

**UT3 · RA3 · Nivel 1** — Acceso y manipulación de documentos web con JavaScript

**RA3:** Accede y manipula documentos web utilizando lenguajes de script de cliente.

**Criterios trabajados:** RA3 a), RA3 b), RA3 c)

## Situación

La web de la almazara tendrá comportamiento propio en el navegador.

## Enunciado

1. Enumera los lenguajes de script de cliente y sus estándares (ECMAScript). Explica qué es el DOM.
2. En `material/carta.html` escribe un script con variables, un `if`, un bucle y una función que calcule el precio medio de la carta y lo muestre en la consola.
3. Selecciona con `getElementById`, `querySelector` y `querySelectorAll` el título, el primer producto y todos los productos de más de 8 euros (`data-precio`).

## Entrega

El script y las capturas de la consola.

## Criterios de aceptación (compruébalos tú)

- La consola muestra el precio medio correcto.
- Los selectores devuelven los elementos esperados.

## Pista

Usa las herramientas del desarrollador (F12) para probar los selectores.
