# 06_ejercicio_UT2 · Estilos: de la estructura al diseño

**UT2 · RA2 · Nivel 3** — Transmisión y presentación de información: HTML5, CSS y sindicación

**RA2:** Utiliza lenguajes de marcas para la transmisión y presentación de información a través de la web analizando la estructura de los documentos e identificando sus elementos.

**Criterios trabajados:** RA2 f), RA2 g), RA2 h)

## Situación

La web debe tener la imagen corporativa (verde oliva) y adaptarse al móvil.

## Enunciado

1. Explica tres ventajas de las hojas de estilo y por qué es mejor un fichero externo que el atributo `style`.
2. Crea `estilo.css` con selectores de etiqueta, clase, id y descendiente; cabecera verde, tarjetas con borde redondeado y tabla con bordes.
3. Añade una consulta de medios (`@media`) para pantallas de menos de 600 px y explica la especificidad con un ejemplo.
4. Valida el HTML y el CSS con las herramientas del W3C y corrige lo que aparezca.

## Entrega

`estilo.css`, capturas en escritorio y móvil, y el informe de validación.

## Criterios de aceptación (compruébalos tú)

- Hay al menos un selector de cada tipo.
- La página cambia de aspecto en pantallas estrechas.
- El validador de CSS no muestra errores.

## Pista

Las reglas se aplican según su especificidad y, a igualdad, la última gana.
