# 13_ejercicio_UT5 · Convertir sin duplicar

**UT5 · RA5 · Nivel 1** — Conversiones sobre documentos: XPath, XSLT y XQuery

**RA5:** Realiza conversiones sobre documentos para el intercambio de información utilizando técnicas, lenguajes y herramientas de procesamiento.

**Criterios trabajados:** RA5 a), RA5 b), RA5 c), RA5 f)

## Situación

La almazara guarda su catálogo en XML y necesita una web, un CSV para contabilidad y un PDF para imprimir.

## Enunciado

1. Explica por qué es mejor convertir desde una única fuente que mantener tres copias y enumera cuatro ámbitos de aplicación de las conversiones.
2. Describe cómo funciona XSLT (documento origen, hoja de estilos, procesador, documento resultado) y compáralo con XQuery y con DOM/SAX.
3. Enumera herramientas de conversión (Saxon, xsltproc, Pandoc, LibreOffice, Apache FOP) y elige una para cada caso.

## Entrega

Un documento con las tres respuestas.

## Criterios de aceptación (compruébalos tú)

- La respuesta justifica la fuente única.
- Cada herramienta se asocia a un formato de entrada y de salida.

## Pista

Piensa en qué ocurre cuando cambia un precio.
