# Lenguajes de marcas y SGI · ejemplos interactivos

Sitio web con ejemplos para practicar (1.º DAW): comprobador de XML, probadores de XPath y XSLT, probador de DOM, páginas HTML/CSS de ejemplo y ficheros de datos.

Todos los datos son ficticios. Sin soluciones de ejercicios ni pruebas.

Incluye `xslt-polyfill` (BSD-3-Clause) en `assets/` para que el probador de XSLT funcione en navegadores sin soporte nativo.
